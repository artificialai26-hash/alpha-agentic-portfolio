## ⚡ Overview
A hacker-terminal / retro-CLI aesthetic personal portfolio fused with a glowing AI mascot visual layer. Built with a Python-first static generator and powered by a FastAPI interactive agent backend.

## 🛠 Tech Stack
- **Site Generator:** Python (Jinja2 + Markdown Parsing)
- **Backend Service:** FastAPI, Uvicorn, LangChain/Groq Integration
- **Frontend:** HTML5, Modern CSS3 (CRT & Holographic HUD styling), Vanilla JS
